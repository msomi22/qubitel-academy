# AI Agent Skill: Qubitel Academy Universal Markdown Content Generation

## Description
This skill defines the strict formatting rule for generating Markdown files in this repository. Every Markdown file must be entirely enclosed within a single, unified Markdown code block.

## Core Rule
Whenever you are asked to generate or update a Markdown (`.md`) file, put the *entire* instruction set or document content inside one single top-level Markdown code block. Do not separate sections with multiple code blocks or leave parts outside of the primary code block wrapper.
