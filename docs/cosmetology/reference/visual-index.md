# Cosmetology Visual Index

This file tracks instructional visuals required across the cosmetology course.

A figure should be added to this index as soon as the chapter outline identifies that the learner needs to **see** something to understand it properly.

## Status Values

- **Planned** — visual requirement identified.
- **Draft** — illustration exists but requires review.
- **Review** — scientific/label review in progress.
- **Complete** — approved and embedded in the student notes.

## Rule

A module cannot move to **Complete** status until all visuals identified as instructionally required for that module are either:

1. created, approved, and embedded; or
2. explicitly documented as not required after review.
